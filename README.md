# Seagrass pH Refugia Project

This project analyzes seagrass meadows as potential refugia from ocean acidification by examining pH, DIC, and TA data from various sources including Copernicus, GLODAP, SOCAT, and PyCO2SYS calculations.

## Data Sources
- Copernicus Marine Service
- GLODAP (Global Ocean Data Analysis Project)
- SOCAT (Surface Ocean CO2 Atlas)
- PyCO2SYS calculations

## Analysis
The project processes marine carbonate chemistry data to identify seagrass meadows that may provide localized relief from ocean acidification effects.
