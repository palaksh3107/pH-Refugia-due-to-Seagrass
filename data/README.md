# Data Directory

This directory contains raw data files and intermediate data products that are 
NOT intended for inclusion in the Git repository. These files are typically:
- Large raw datasets
- Intermediate processing files
- Files that can be regenerated from source code and raw data

## Organization
Data files are organized by source/type into subdirectories:

- `copernicus/` - Copernicus Marine Service data
- `glodap/` - GLODAP (Global Ocean Data Analysis Project) datasets
- `socat/` - SOCAT (Surface Ocean CO2 Atlas) measurements
- `pyco2sys/` - Intermediate results from PyCO2SYS calculations
- `cmems/` - CMEMS (Copernicus Marine Environment Monitoring Service) NetCDF files
- `seagrass/` - Seagrass meadow boundary and habitat data
- `misc/` - Miscellaneous small files

## Note on File Sizes
Some files in this directory are very large (hundreds of MB to several GB) 
and would make the repository unwieldy if included in version control.

## Regenerating Data
Most files in this directory can be regenerated by running the appropriate 
processing scripts in the src/ directory, assuming access to the original 
raw data sources.
