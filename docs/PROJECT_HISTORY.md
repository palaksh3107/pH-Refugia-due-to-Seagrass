# Project History

## Initial Data Collection (2023-2024)
- Acquired Copernicus marine data for seagrass regions
- Downloaded GLODAPv2.2023 Atlantic Ocean dataset
- Retrieved SOCATv2023 gridded coastal monthly data
- Collected in situ measurements from NOAA seagrass monitoring

## Processing Pipeline Development (2024)
- Developed PyCO2SYS-based processing scripts
- Created validation routines for data quality control
- Implemented machine learning approaches for gap filling
- Built uncertainty quantification frameworks

## Analysis Phase (2024-2025)
- Calculated monthly pH, DIC, and TA anomalies
- Compared seagrass vs open water carbonate chemistry
- Identified potential refugia based on pH buffering capacity
- Generated maps and time series visualizations

## Current Status (2026)
- Data processing pipelines established
- Key analyses completed and validated
- Manuscript preparation in progress
- Data and code organization for reproducibility
